3. Read replicas for reads you can't cache

Read replica: a copy of the database that only answers reads. The primary takes every write and sends each change to the replicas. Example: search results and order history read from a replica.
costreplication lag: a user saves a new address, the next page reads a replica, and shows the old one for a moment.
limitno help for writes. Every write still lands on the one primary.
