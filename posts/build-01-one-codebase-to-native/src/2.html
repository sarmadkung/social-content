Did cross‑platform manage everything for us?

No. One codebase on paper. Underneath, we still handled each platform by hand:
Librariesmany work only on native or only on web; each needs a fallback
Web vs native APIslocalStorage on web, camera and files on phones: two code paths
Logs and crashesXcode, Logcat, browser console; crash symbols per platform
PermissionsInfo.plist on iOS, manifest on Android, prompts on web
NotificationsAPNs on iOS, FCM on Android, web push on web
Platform actionsshare sheet, deep links, background tasks: different on each OS
UI detailssafe areas, keyboard, Android back button vs iOS back gesture
Testingeach platform on its own devices and simulators
that is the work native apps do anyway, so going native cost less than it looked
