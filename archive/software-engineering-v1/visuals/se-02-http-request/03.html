DNS turns a name into a number

Your code knows a name. The network needs an IP address. DNS (Domain Name System) is the internet's phone book.

first call
api.example.com
→ask DNS
203.0.113.7
repeat
api.example.com
→cache
203.0.113.7
cached

Answers are cached, so the repeat lookup is fast.
If the name cannot be found, nothing else runs.
