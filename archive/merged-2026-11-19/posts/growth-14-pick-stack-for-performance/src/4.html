What changes in a real job?

the job: import a customer's 2 GB CSV file every night
BEFORE · THE STACK WE KNEW
Node.js reads one row at a time, on one thread
8 CPU cores
1 busy7 idle
it takes about 40 minutes, and longer with every new customer
AFTER · THE ENGINE THE JOB NEEDS
Option A: DuckDBload the CSV into DuckDB and do the totals in SQL; it reads by column and uses every core
Option B: Go or Rustthe agent rewrites only the parser, with one worker on each CPU core
all 8 busy
the rest of the app stays in TypeScript
YOUR PART
1Write the spec, with a time target: "a 2 GB file in under 5 minutes"
2Give the agent the test file the old version used
3Review the diff, then time both versions on a real 2 GB file
Hot path: the small part of the code where most of the time goes. Here, the parser that reads the file.
