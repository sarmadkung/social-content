Step 0: measure, don't guess

pg_stat_statements is a PostgreSQL extension that counts every query: how often it ran and how much time it used in total. MySQL: the slow query log.
=# SELECT query, calls, mean, total
   FROM pg_stat_statements
   ORDER BY total DESC LIMIT 3;
querycallsmeantotal
orders WHERE user_id=$114,000380 ms5,320 s
products WHERE id=$1800,0000.9 ms720 s
carts WHERE user_id=$130,00012 ms360 s
read itSort by total time (calls × mean). The query that runs most often is not the problem here; one slow query is. Fix that one first.
