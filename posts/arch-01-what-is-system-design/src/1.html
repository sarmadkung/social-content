System Architecture #01

System design: how the parts fit together

serverA computer that runs your code and answers requests. Example: the machine that sends back your feed when you open an app.
databaseStores data so it is still there after a restart. Example: every order a shop has ever taken.
cacheA fast, short-lived copy of data that is read often. Example: today's top products, kept in memory.
queueA waiting line of jobs to do later, so the user doesn't wait. Example: "send the receipt email", done by a worker.
