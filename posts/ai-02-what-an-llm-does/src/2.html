The picka weighted random draw. Run it 100 times: about 79 say Islamabad, about 11 say Lahore. It picks likely text. It does not look anything up.
Logit (score): the raw number the model gives each possible next token. Higher means more likely. Example: Islamabad 5.0, Lahore 3.0.
Softmax: a formula that turns the scores into probabilities that add up to 100%. Example: 5.0, 3.0, 2.5, 1.5, 0.5 → 79.4%, 10.8%, 6.5%, 2.4%, 0.9%.
Illustrative numbers: imagine the model knows only these 5 tokens. A real one scores every token it knows. Settings like temperature reshape the odds before the pick (#05).
