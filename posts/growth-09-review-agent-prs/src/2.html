Dev Growth #09

Review in this order: intent first

CHECKLOOK FOR
01intentread the ticket first. does the PR do
that: no more, no less?
02scopeconfig, CI, lockfiles, "while I was
here" refactors → separate PR
03tests before coderead the test diff first, and hardest
04risky pathsauth, payments, deletes, migrations,
retries, logged user data
05fitnew dependency? helper written twice?
a pattern the team doesn't use?
06run it yourselfthe PR summary is a claim, not proof
07can you explain it?no → ask why, or ask for a smaller PR
