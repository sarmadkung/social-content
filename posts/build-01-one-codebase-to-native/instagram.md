I work with a team of engineers on a great app with a lot of users. It started cross-platform: one codebase for iOS, Android, web and desktop. There were no coding agents back then.

Keeping it working got harder. A fix for one platform broke another. We knew native was better, but a rewrite was too big, with too much else up in the air.

Now agents write the native code from one set of rules, and tests keep the apps in sync. So we took the app native, in weeks, not years.
