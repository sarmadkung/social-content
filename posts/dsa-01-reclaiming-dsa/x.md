Patterns. After enough sliding-window problems, a "new" problem is one you already know: a window that grows and shrinks.

Most problems are a few patterns in disguise.
---
One problem, many ways. Two Sum:
→ check every pair: O(n²)
→ sort + two pointers: O(n log n)
→ one pass + hash map: O(n)

Each way is a different trade-off.
---
It's inside the tools you use. An LRU cache is a hash map + a linked list. A DB index is a B-tree.

And AI itself: RAG search is graph search, training is graph traversal.

→ learn the pattern, not the answer
→ depth beats count
→ use AI as a tutor, not an answer key
→ small and steady, 30–45 min a day
