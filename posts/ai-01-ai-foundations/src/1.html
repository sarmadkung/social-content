AI Engineering #01

Each one sits inside the last

AI
Any program that does a task we'd call smart. It doesn't have to learn anything.
Example: a spam filter with one rule a person wrote: if an email says "free money", mark it as spam.
Machine learning
The program learns the rules itself, from examples. Nobody writes them.
Example: show it 10,000 emails marked "spam" or "not spam". It learns what spam looks like.
Deep learning
Machine learning with a neural network of many layers. It learns from raw text, photos and sound.
Example: a photo app that finds the faces in your pictures.
LLMs large language models
Deep learning trained on huge amounts of text, so it can read and write language.
Example: the model behind a chat app. You type a question, it writes the answer.
