Kadane is prefix sum in disguise

a = [2, -1, 3, -4, 5]  →  running totals pre = [0, 2, 1, 4, 0, 5]
Best subarray sum = the biggest gap between a running total and the lowest total before it. Here 5 − 0 = 5, the same answer Kadane gives.
Kadane keeps that gap as it walks (cur), so it never stores the totals: O(1) space instead of O(n).
