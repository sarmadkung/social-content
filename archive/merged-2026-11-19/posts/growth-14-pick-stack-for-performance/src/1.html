Dev Growth #14

What used to decide the stack?

the questions teams asked, in this order:
1
What does the team already know?learning a new language took months
AGENTS WRITE ANY LANGUAGE
2
How fast can we write it?writing the code was the slowest, most expensive part
AGENTS WRITE IT FAST
3
Who can we hire for it?it was hard to hire people who knew a rare language
MATTERS LESS NOW
4
How fast will it run?teams asked this last, or never asked it
DID NOT CHANGE
agents write the code and a person reviews it, so the first three questions matter much less. how fast it runs now decides the stack.
