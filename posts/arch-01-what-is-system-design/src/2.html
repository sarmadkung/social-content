System Architecture #01

Five things every design trades

scalabilityCan it serve more users if we add machines?
availabilityDoes it stay up when one part fails?
latencyHow long does one request take?
consistencyDoes every user see the same, correct data?
cost + simplicityWhat does it take to run it and to change it?
you can't max them all. two examples:
add a cache
gain: faster reads (latency)
cost: older data (consistency)
add more servers
gain: more users (scalability)
cost: a bigger bill, more to run (cost)
