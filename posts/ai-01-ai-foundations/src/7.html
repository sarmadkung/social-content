AI Engineering #01

Predicting is just running the maths

Prediction: you give the trained model a new input it has never seen, and it gives an answer. It uses the weights training found. It learns nothing new.
Example 1 · house price · training found w = 100
new input
a house with
4 rooms
→
run the maths
price = 100 × 4
w stays 100
→
answer
400
Example 2 · spam filter · same weights as before
new email
links: 0
"free": 0
known sender: 1
→
run the maths
0.9 × 0 + 1.4 × 0
− 2.0 × 1 = −2.0
→
answer
not spam
−2.0 is below 0.5
Every model predicts this way: input → numbers → multiply by weights and add → answer. A big model just has billions of weights.
