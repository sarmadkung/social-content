sort() does not sort numbers

sort.jsdefault comparator
1// no comparator: items are compared as strings
2[1, 10, 2].sort(); // [1, 10, 2]
3// "10" comes before "2", because "1" < "2"
4[1, 10, 2].sort((a, b) => a - b); // [1, 2, 10]
5
6// the comparator must return a number
7users.sort((a, b) => a.age > b.age); // true/false
8users.sort((a, b) => a.age - b.age); // -, 0 or +
Comparator: the function you pass to sort(). It gets two items, a and b, and returns a number: negative puts a first, positive puts b first, 0 means they are equal.
