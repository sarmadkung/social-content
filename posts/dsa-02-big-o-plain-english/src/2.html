Four rules of reading Big-O

01drops constants
3n steps → O(n)
Hides real costs. An array walk and a linked-list walk are both O(n). The array is faster: it reads memory in order, which the CPU cache loves.
02drops smaller terms
n² + n → O(n²)
At n = 1,000: n² is 1,000,000 steps and n adds only 1,000 more. The biggest term wins as n grows.
03usually the worst case
find x in n items → O(n)
Best case: x is first, 1 step. Worst case: x is last or missing, n steps. Say which case you mean.
04works for memory too
copy an array → O(n)
Summing an array needs one extra number: O(1) space. Copying it needs n new slots. That is space complexity.
