Why do performance and native support matter more now?

1
More data per userapps store messages, files, events and embeddings, and search all of them
2
More work per requestone request may rank results, call an AI model, resize images and sync live
3
AI calls are already slowa model call can take seconds, so the rest of the request has no time to waste
4
The cloud bill follows CPU and memorysay a runtime needs twice the memory per request: you pay for about twice the servers
5
Users feel itnative apps start faster and scroll smoother (more in DEV GROWTH #13)

Embeddings: lists of numbers that capture what a piece of text means, so a search can find text with the same meaning.

Example: "cheap flights" and "low-cost airfare" get numbers that sit close together, so a search for one finds the other.
