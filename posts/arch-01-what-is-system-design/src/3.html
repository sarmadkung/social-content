System Architecture #01

Five steps, then repeat

example: a photo-sharing app
1What must it do?post a photo, see friends' photos
2How well?say 1M users, feed opens in under 1 s, stays up if a server dies
3Simplest versionone app server + one database
4Where it breaksat peak, every feed open reads the database
5Fix that one partkeep each feed in a cache
↻ back to step 4: more users find the next weak spot.
