Which stack for web, mobile and desktop?

my defaults in 2026: opinions with reasons, not rules
Web appSaaS, dashboards
DEFAULTTypeScript + React (Next.js) + Postgresone language for UI and server, the biggest library and hiring pool
PICK SOMETHING ELSE WHEN

mostly content (blog, docs) → Astro

Mobile appiOS and Android
DEFAULTSwift (SwiftUI) + Kotlin (Compose)new OS features on day one, no extra layer between code and phone
PICK SOMETHING ELSE WHEN

simple screens, tiny team, no hardware work → React Native or Flutter

Desktop appmacOS, Windows, Linux
DEFAULTTauri (Rust core + web UI)uses the OS's own web view, so the installer is a few MB
PICK SOMETHING ELSE WHEN

same rendering everywhere or Node.js libraries → Electron
