Every += copies
the whole string

Immutable: a string can't be changed after it is made, so every "change" builds a new string. Example: out += "O" makes a new string "HELLO" and copies H, E, L, L into it first.
out += c, building HELLO
Hcopy 1 HEcopy 2 HELcopy 3 HELLcopy 4 HELLOcopy 5
1+2+3+4+5 = 15 ≈ n²/2
parts.push(c), then join
parts:
HELLO
join → HELLOcopy 5
each char once = 5 = n
n = 1,000: ~500,000 copies, so small tests pass
n = 100,000: ~5,000,000,000 copies vs 100,000
