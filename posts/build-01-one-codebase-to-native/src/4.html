Who keeps the apps in sync now?

BEFORE
The framework
there is only one copy of the code
same code on every platform
same compromises in every app
a fix reaches every app, and so does a bug
NOW
Agents + one rules file
the file every agent session reads first
build on web first, agents port it
a fix lands in every app it affects
shared behaviour names the native code to change
a person owns each native app
shared tests fail the build if a port is skipped
the framework synced the code. agents sync the behaviour.
