System Architecture #10

1. Add the missing index

Index: a sorted lookup the database keeps next to a table, like the index at the back of a book. Example: user_id 42 → rows 1,207, 88,410, 3,901,155.
no index
read all 5,000,000 rows
check each one, keep the few that match user 42
index on user_id
jump straight to user 42's rows
look up 42 in the sorted index, read only those rows
CREATE INDEX orders_user_id ON orders (user_id);
alsoN+1 queries: 1 query for a list of 100 orders, then 1 more per order = 101 trips. Fetch them in one query instead.
costevery index makes writes a little slower and uses disk.
