AI Engineering #08

The model asks. Your code runs.

01your app
Sends the user's message and the list of tools.
"Where is order A123?" + tools: getOrder(id)
↓
02model
Replies with a request, not an answer.
{ "tool": "getOrder", "args": { "id": "A123" } }
↓
03your code
Checks the arguments and permissions, then runs it.
getOrder("A123") → { "status": "shipped", "eta": "Fri" }
↓
04your app
Sends the result back to the model.
↓
05model
Writes the answer, or asks for another tool.
"Order A123 has shipped. It should arrive Friday."
↺ another tool request → back to step 03
Tool: a function in your code that you let the model ask for. Example: getOrder(id) looks up one order in your database.
