In one meeting you can hear "AI", "ML" and "LLM" used for the same thing. They are not the same thing. Each one sits inside the one before it.

The shared problem
All four words are about the same goal: getting a computer to do tasks that seem to need human thinking. They differ in how the computer gets there.

The four words
AI (artificial intelligence) → the broad goal. Any program that does a "smart" task. It can use hand-written rules.
Example: a classic chess program that searches moves using rules a person wrote.

ML (machine learning) → a way to reach that goal. The program learns patterns from examples (data) instead of following rules someone typed.
Example: a spam filter that learns from thousands of emails marked "spam" or "not spam".

Deep learning → a kind of ML that uses neural networks: many layers of simple maths units, stacked. Good with messy data like images, sound and text.
Example: a photo app that finds faces.

LLM (large language model) → a deep learning model trained on a huge amount of text. It works with language.
Example: a chat assistant or a coding assistant.

The picture
AI ⊃ ML ⊃ deep learning ⊃ LLM
Every LLM is deep learning. Every deep learning model is ML. Every ML system is AI. Not the other way round.

Which word to use
→ Talking about the whole field or the goal: AI.
→ The system learns from data: ML.
→ It uses neural networks: deep learning.
→ It reads and writes text: LLM.

The common confusion
"AI" now often means "a chatbot". So people think AI and LLM are the same, or that every AI feature needs an LLM. Many good AI features are a small ML model, or even plain rules. A fraud score on a bank payment is usually classic ML, not an LLM.

Where AI engineering sits
Researchers and ML engineers build and train models. AI engineers build products on top of them. Most of the time you call a model someone else trained, and your job is everything around it: inputs, outputs, cost, errors, checks. That is what this series covers.
